References
==========

Course specification
--------------------

B. Bolliet, *Research Computing*: specification for a
five-dimensional regression application with a Python package, REST API,
web interface, tests, documentation and container configuration.

Software documentation
----------------------

* `Keras Sequential API <https://keras.io/api/models/sequential/>`_:
  the dense neural-network model.
* `FastAPI documentation <https://fastapi.tiangolo.com/>`_:
  request validation and the training and prediction endpoints.
* `Next.js documentation <https://nextjs.org/docs>`_:
  the web application and routing.
* `NumPy savez documentation <https://numpy.org/doc/stable/reference/generated/numpy.savez.html>`_:
  storing named numerical arrays in an NPZ archive.
* `scikit-learn StandardScaler documentation <https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html>`_:
  feature standardisation using training-set statistics.
